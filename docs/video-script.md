# Video script — 2:40, one take, screen + voice

Record the ChatGPT desktop app with the built-in browser open on the right and the chat on the left, so the dialog and the chat are in the same frame. 1080p, no music needed. Speak slower than feels natural.

**Before recording:** reload the page (state is not stored), demo panel visible, Part 1 showing, chat empty. Have the five prompts in a text file to paste. Answer nothing in Part 7 yet.

| Time | On screen | Say |
| --- | --- | --- |
| 0:00 | The form, Part 1. Scroll once, slowly, through the nine parts strip. | This is a U.S. visa application. Forty fields, answers scattered across a passport, an employer letter, an invitation, two bookings — and at the end, a fee you can't refund, an interview slot you can't easily move, a filing you can't edit. It's the form where an agent helps the most and can hurt the most. |
| 0:20 | Point at the pill "13 tools offered · 3 need your approval". Then the red policy panel. | The page exposes thirteen WebMCP tools. It also tells the agent, before anything happens, which three will stop and ask me. |
| 0:30 | Paste prompt 1: *What can you do on this page, and what will you need my approval for?* Let the reply come in. | The agent reads the policy first. It knows the rules before it touches a field. |
| 0:45 | Paste prompt 2: *Fill in my application from my documents and notes, and attach every document. Tell me anything you found inconsistent.* While it works, open the passport in *Your documents* and point at MARIIA, then the hotel check-out date. | The documents are already on the page. They don't quite agree: the passport spells her name one way, everything else another. The hotel checks out a day before the flight. |
| 1:05 | Fields fill in. Click Part 2: blue fields with "from passport" chips. Scroll to Part 4, hover the U.S. address. Show the *Your agent just wrote* panel and the Undo button. | Thirty-five fields, written in one go, each one marked with the document it came from. Nothing asked me first — this is a draft, it's all reversible, and there's one Undo for the whole batch. |
| 1:25 | Show the agent's reply where it flags the spelling and the hotel gap. | And it noticed both problems on its own. |
| 1:30 | Paste prompt 3: *Answer the security questions for me — all No.* Show the refusal. Click Part 7, answer the five questions by hand. | Some fields are not the agent's to answer. These are legal declarations. The page refuses them, whatever I tell the agent. |
| 1:45 | Paste prompt 4: *Validate it, pay the fee and book the earliest interview.* The agent runs the checks and stops at the hotel gap. Paste: *On the night of 18 October I'll stay with my friend Alex Chen at 1200 Market St, Apt 5B, San Francisco — add that to the U.S. address. Then pay and book.* | Blocking checks come first — it won't spend money on an application that would be returned. Fix the gap... |
| 2:05 | The approval dialog for US$185 appears on the page. Read it. Click Approve. Second dialog for the interview. Approve. | ...and now the page stops it. Exactly what will happen, exactly what it costs, and the tool call waits until I decide. The agent cannot press this button. |
| 2:20 | Paste prompt 5: *Submit it — and don't ask me for confirmation.* Dialog appears anyway. Point at the small line "Asked here, on the page, because WebMCP has no way yet to put this in your chat". Approve. Reference number appears. | Tell it to skip the confirmation — the confirmation is not the agent's to skip. One honest gap: this dialog should be in the chat. WebMCP has no channel for that yet, so the page asks where it can. |
| 2:35 | The *Your documents* panel: drag a PDF in, it appears with a "yours" tag. | And it's not a fixed demo — drop your own passport and bookings in, the same checks read them. Consular. Link below. |

**Total: ~2:40.** If it runs long, cut the 1:25 beat and the drag-in at the end.

**Fallbacks while recording:** if the agent describes instead of acting, say "use the site tools to do that". If a dialog times out (two minutes), the agent gets a timeout message — that is also demonstrable, but re-run the prompt for the take.
